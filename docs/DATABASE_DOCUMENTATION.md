# Database Documentation — MongoDB Schema & Architecture

## Overview
The Personal Expense Tracker uses **MongoDB** as its primary NoSQL document database.

- **Database Name:** `expense_tracker`
- **Collection Name:** `transactions`

---

## SQL Relational Tables vs. MongoDB Collections (Interview Concept)

| Feature | Relational Database (SQL / MySQL / PostgreSQL) | Document Database (MongoDB) |
| :--- | :--- | :--- |
| **Data Model** | Tables with fixed rows and columns | Collections containing flexible JSON-like BSON documents |
| **Schema** | Rigid schema enforced at table level | Flexible schema allowing evolving document structures |
| **Primary Key** | Integer auto-increment / UUID (often with JPA `@GeneratedValue`) | 12-byte unique `ObjectId` (`_id`) automatically generated by MongoDB |
| **Query Mechanism**| SQL dialects with JOIN operations | Rich JSON query operators and aggregation pipelines |
| **Spring Integration**| Spring Data JPA / Hibernate (`@Entity`, `JpaRepository`) | Spring Data MongoDB (`@Document`, `MongoRepository`) |

## Transaction Document Structure

```json
{
  "_id": { "$oid": "66da91234567890abcdef123" },
  "title": "Supermarket Groceries",
  "amount": 4250.00,
  "type": "EXPENSE",
  "category": "Groceries",
  "transactionDate": { "$date": "2026-09-03T00:00:00.000Z" },
  "description": "Monthly groceries and staples",
  "createdAt": { "$date": "2026-09-03T10:15:00.000Z" },
  "updatedAt": { "$date": "2026-09-03T10:15:00.000Z" }
}
```

### Field Specifications:
1. **`_id` (`String` / `ObjectId`):** Unique identifier generated by MongoDB.
2. **`title` (`String`):** Short description or title of the transaction.
3. **`amount` (`BigDecimal` / `Number`):** Monetary transaction value (must be positive).
4. **`type` (`String` / `Enum`):** Either `INCOME` or `EXPENSE`.
5. **`category` (`String`):** The category classification (e.g. Salary, Rent, Food, Travel).
6. **`transactionDate` (`LocalDate`):** The date on which the transaction took place.
7. **`description` (`String`):** Optional extended notes or details.
8. **`createdAt` (`LocalDateTime`):** Timestamp when the record was initially created.
9. **`updatedAt` (`LocalDateTime`):** Timestamp when the record was last modified.

## MongoDB Connection Configuration

### 1. Local MongoDB
Ensure your local MongoDB service is running:
```properties
# Default URI in application.properties
spring.data.mongodb.uri=mongodb://localhost:27017/expense_tracker
```

### 2. MongoDB Atlas (Cloud)
To connect to MongoDB Atlas without modifying source code, set the `MONGODB_URI` environment variable:
1. Create a free cluster on MongoDB Atlas (https://www.mongodb.com/atlas).
2. Create a Database User with read/write permissions.
3. In Network Access, add your IP address (or `0.0.0.0/0` for development).
4. Copy the connection string and set the environment variable:
   - **Windows (PowerShell):**
     `$env:MONGODB_URI="mongodb+srv://<username>:<password>@cluster0.mongodb.net/expense_tracker?retryWrites=true&w=majority"`
   - **Linux / macOS:**
     `export MONGODB_URI="mongodb+srv://<username>:<password>@cluster0.mongodb.net/expense_tracker?retryWrites=true&w=majority"`
